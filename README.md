# Haruka.bot

# Discord Bot - Gerenciador & Entretenimento

## Sobre o Bot
Este bot do Discord foi desenvolvido para oferecer funcionalidades de moderação, entretenimento e interação com a comunidade. Ele inclui recursos de administração, notificação de transmissões ao vivo, minigames, integração com o Minecraft e um sistema de sound pad para diversão no servidor.

## Funcionalidades

### 🛠️ Administração e Moderação
- Comandos para banir, expulsar e silenciar usuários.
- Gerenciamento de mensagens, como limpar mensagens em massa.
- Sistema de warns para controle de infrações.
- Controle de permissões e roles dos usuários.

### 🎧 Notificação de Stream
- O bot detecta automaticamente quando um usuário começa uma transmissão ao vivo no Discord.
- Atualiza a presença/status do bot para indicar que a transmissão está ativa.
- Possibilidade de configurar mensagens automáticas de notificação no servidor.

### ⛏ Minigame baseado em Minecraft
- Sistema de mineração onde os jogadores podem coletar recursos.
- Economia própria dentro do jogo.
- Controle de estamina e evolução do personagem.
- Possibilidade de obter loot raro e subir de nível.

### 🎮 Wiki de Minecraft
- Comando para consultar informações sobre blocos, itens e criaturas do Minecraft.
- Atualizações constantes para manter as informações relevantes.

### 🌍 Perfil de Conta de Minecraft
- Integração com contas do Minecraft.
- Possibilidade de exibir skins e estatísticas do jogador.
- Consulta de informações sobre servidores de Minecraft.

### 🎵 Sound Pad
- Sistema de efeitos sonoros ativados por comando (01/24).
- Possibilidade de tocar áudios específicos para animação no chat de voz.
- Personalização de áudios pré-definidos.

## Como Usar
1. Adicione o bot ao seu servidor.
2. Utilize os comandos disponíveis conforme as permissões concedidas.
3. Configure os módulos desejados de acordo com a necessidade da comunidade.

## Instalação
Para hospedar o bot localmente:
```bash
# Clone o repositório
git clone https://github.com/Exxxtriker/Haruka-bot.git

# Instale as dependências
npm install

# Configure o arquivo .env com suas credenciais

# Inicie o bot
node index.js
```

## Configuração
- Utilize um arquivo `.env` para armazenar tokens e credenciais.
- Personalize comandos e permissões no arquivo de configuração do bot.
